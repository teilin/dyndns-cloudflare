Your IP moves.
Your DNS keeps up.

A tiny dynamic-DNS daemon that watches your public IP and, the moment it changes, re-points your Cloudflare A record — so vpn.devgeek.io (or any host) always resolves to you. No Python. No Node. No bloat.

Why this exists

Most home/VPN setups sit on a dynamic IP. Many solutions bolt a heavyweight runtime onto a NAS just to update one DNS record. This one is a single static binary.

⚡Truly minimal

One statically-linked Zig binary in a ~4 MB Alpine container. Nothing else runs.

🔐TLS by default

HTTPS end-to-end using Zig's own TLS stack with system CA verification.

🧠Smarts, not storms

Only calls the Cloudflare API when your IP actually changed — no churn, no rate limits.

🛡️Stateful

Persists the last-known IP to a volume, so restarts don't force pointless updates.

🪶Self-hosted

Runs on any NAS, Pi, or VPS with Docker. Your credentials never leave your network.

🐧Cross-platform

Static musl build. Runs anywhere an amd64 container runs, with no fragile runtimes.

How it works

Run it, forget it. Each pass is four steps and returns quickly when nothing changed.

3

4

— happy path: 1 HTTP GET, 0 writes, exited 0 —

Install

Pull from GitHub Container Registry and run it with four env vars. That's the whole setup.

# 1. pull the public image
docker pull ghcr.io/teilin/dyndns-cloudflare:latest

# 2. run it (drop the -d and add --rm for a one-shot check in the foreground)
docker run -d --name dyndns \
  -e CLOUDFLARE_API_TOKEN="$CF_API_TOKEN" \
  -e CLOUDFLARE_ZONE_ID="$CF_ZONE_ID" \
  -e CLOUDFLARE_RECORD_ID="$CF_RECORD_ID" \
  -e CLOUDFLARE_RECORD_NAME=vpn.devgeek.io \
  -v dyndns-state:/config \
  --restart unless-stopped \
  ghcr.io/teilin/dyndns-cloudflare:latest

Mount a named volume on /config so the last-known IP survives container restarts.

Configuration

All configuration is via environment variables — no config file, no YAML.

VariableRequiredPurpose
CLOUDFLARE_API_TOKENyesAPI token with Zone → DNS → Edit permission
CLOUDFLARE_ZONE_IDyesZone ID for the domain (devgeek.io)
CLOUDFLARE_RECORD_IDyesDNS record ID of the A record to update
CLOUDFLARE_RECORD_NAMEyesFQDN of the record, e.g. vpn.devgeek.io

Tip: find ZONE_ID and RECORD_ID via the Cloudflare API, or grab them from the URL of the dashboard / API responses when you look up the record.
